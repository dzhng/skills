# Composition Patterns and Originality Rules

## Basic composition types

Choose one primary structure. Do not mix too many at once.

### Workflow

Use for: input → processing → output, content production, AI workflows, automation chains.

Draw: input on the left, Xiaohei or a strange machine in the middle, output on the right. Use orange arrows for the main flow.

### System fragment

Use for: information sources, filters, databases, renderers, or one part of an agent system.

Draw: only 3–5 core modules, with Xiaohei participating in one key action.

### Before / after

Use for: chaos/order, manual/automatic, scattered/collected, anxious/stable.

Draw: messy state on the left, stable state on the right, one orange arrow between them. The character can be more exaggerated.

### Role state

Use for: user pain points, creator states, tool overload, information anxiety, stuck-to-running transitions.

Draw: 2–4 small states, each with one short English label.

### Concept metaphor

Use for: content factories, information warehouses, mental black boxes, workflow machines, automated reports.

Draw: one memorable strange object or machine, a few inputs, and one output.

### Method layers

Use for: methodology frameworks, system layers, capability stacks, content-system layers.

Draw: stacked or leaning boxes, but not a formal pyramid. Xiaohei can carry or assemble pieces nearby.

### Map / route

Use for: idea-to-launch, user journeys, handoff paths, learning routes.

Draw: one winding path, a few nodes, and Xiaohei pulling, walking, cutting, or scouting.

### Mini comic

Use for: failure-to-success, real process, a complaint, before/after use.

Draw: 2–4 small scenes, each expressing one action.

## How to invent an original metaphor

Invent a new metaphor from the current article every time. Do not reuse old images.

### Three steps

1. Turn the abstract idea into a physical action: stuck, leaking, getting heavier, sorting, settling, fermenting, opening, folding, unpacking, returning, slicing.
2. Turn the system structure into a low-tech object: broken machine, cardboard box, drawer, pipe, mailbox, strange gauge, scale, well, ladder, odd workstation.
3. Give Xiaohei the action: not standing nearby, but stuck in the machine, pulling the wrong line, guarding the door, carrying, repairing, weighing, holding a ladder, recording, or stuffing something into a strange device.

## Object pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, tangled cord, gate, turntable, black box, hole punch, noodle press, clothesline, strange workstation.
- Choose only 1–2 objects per image. Do not pile them up.

## Xiaohei action pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, disassemble, mark, recycle.
- The action must serve the core idea. Do not be strange just for the sake of it.

## Anti-copying rules

Do not open or copy `assets/examples/` by default. Those images are only for calibrating line density, white space, color restraint, and Xiaohei's demeanor.

Unless the user explicitly says “copy this,” “recreate this composition,” or “edit this example,” do not reuse these known compositions:

- Conveyor belt with two breakpoints.
- Xiaohei pulling a judgment lever inside a content machine.
- Xiaohei as a funnel sorting traffic, trust, or conversion.
- Xiaohei cutting a source fish.
- Xiaohei pulling a handoff path.
- Xiaohei pulling three layers of information sources.
- Three Xiaoheis holding a megaphone, building a bridge, or opening a door.
- Xiaohei stamping phrases in a copy toolbox.
- Xiaohei holding a warning sign near a common-pitfalls path.

Even for similar themes, invent a new metaphor. For example, a handoff path does not have to be a route; it could be Xiaohei connecting a loose thread to a door handle. Reuse does not have to be a fish; it could be Xiaohei pressing one paper ball into several shapes.
